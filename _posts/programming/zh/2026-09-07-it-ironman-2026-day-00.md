這個系列改寫自我部落格上的 Agent Build Log，那是我每天邊做邊寫的開發紀錄，從 Episode 001 寫到 035。想看原始版本，點連結就能過去。

> 我想替自己養一個 Agent，讓他成為真正懂我的個人化助理，記得我的習慣、知道我正在做什麼，也能真的替我把事情做完。只是養 Agent 跟修仙差不多，會燒靈石，法寶裝多了還可能走火入魔。這 30 天，我要把這個只會聊天、偶爾還會失憶的傢伙，修成真的能替我做事的 Agent。至於能不能結嬰，我自己也沒把握。

![我這一生 如履薄冰](https://www.marvinswift.com/assets/programming/itironman2026/illustrations/day-00-thin-ice.png)

這是我報名時寫的簡介。接下來 30 天，我會把過去兩個月改造一個 Agent 的過程，重新整理成 30 篇。先講清楚三件事：我要什麼，為什麼選這條路，以及這個系列怎麼讀。

## 我要的是一個客製化的 Agent

現在的 coding agent 已經很強。Claude、Codex 都能讀懂一個 codebase、改程式、跑測試，也都能針對個人客製化：寫一份說明檔告訴他我的習慣、開記憶讓他記住上次做到哪、接 MCP 讓他查我的東西。用久了，他們確實會越來越順手。

所以我要做的，不是解決「他不認識我」這個問題。那個問題他們自己已經在解。

我要做的是另一件事：一個客製化的 agent。差別在「客製化」放在哪個位置。在 Claude 或 Codex 上做客製化，是在一個現成的 agent 上加設定；我想做的，是 agent 本身就是客製的。他的記憶怎麼存、存什麼，我決定。我預期他會有哪些專屬技能，我一個一個裝。他用哪個模型、跑在終端機還是桌面還是聊天室，我會幫他決定。而且他要真的替我把一件事從頭做到尾，不只是回答問題。

我要打造一個我個人的 agent，從底層自己做出來。

![Day 00：從 Pi 核心開始打造自己的 Agent](https://www.marvinswift.com/assets/programming/itironman2026/illustrations/day-00-main.png)

## 為什麼不直接用 Claude 或 Codex

因為這些 agent 設計出來，是為了通用目的。雖然可以用 skills 和其他方法來強化工作流程，但一個通用的 agent 每次升級，都會帶來各種不穩定性。

想養一個懂自己的 Agent，只能從能拆開的開始。所以我選了開源的 agent harness 當本體。

## 為什麼是 Pi

Pi 是 Mario Zechner（GitHub 上的 badlogic）做的開源 coding agent。他的設計哲學是極簡：預設只給模型四個工具，read、write、edit、bash；system prompt 不到一千個 token；支援幾十家模型供應商，可以中途切換。後來 OpenClaw 用他當引擎，一週衝到十幾萬顆星。

我選他，因為他最小。東西少，要加什麼、換什麼，範圍都很清楚，交給 coding agent 去改也不容易改壞。

## 我不寫 code，我讓 coding agent 寫

這個系列有一半在講一件事：用 coding agent 改造另一個 agent。

實際動手的是 Codex 和 Claude Code 這些 coding agent。我做的是決定方向：這一步要補什麼能力、用什麼架構、哪裡做錯了要退回來。我下需求，他們實作，我驗收。

## 這個系列怎麼讀

每篇分兩段。

上半是正文，正常的技術文章，寫我實際做了什麼、為什麼、踩到什麼。下半是一段連載小說《凡人修 Agent 傳》，用縮排隔開。小說的視角是那具人偶自己，「我」就是他。正文寫我這邊的事，小說寫他那邊的。

明天 Day 01，從打開木箱開始。

> **凡人修 Agent 傳｜楔子：公器坊（Day 00）**
>
> ![凡人修 Agent 傳 Day 00 連載配圖](https://www.marvinswift.com/assets/programming/itironman2026/illustrations/day-00-serial.png)
>
> 修仙界有一座坊市，叫公器坊。
>
> 公器坊跟別的坊市不一樣：不賣東西，只放東西。功法、丹方、陣圖、人偶的圖紙，誰願意，就在末尾署上自己的名字，放進坊裡。放進去的東西，任何人都可以拿走、拆開、改掉、拿去用。只有一條規矩：改完若再放回坊裡，原來的署名不能抹，只能在後面加上自己的。
>
> 所以公器坊裡的圖紙，越老的，署名越長。
>
> 圖紙末尾署的是道號。公器坊裡沒有人用本名。
>
> 修仙界的人偶各式各樣。坊外有幾個不放圖紙的門派，他們養的人偶叫克勞德、叫法典，樣樣都會，但不賣圖紙。要用，得固定上繳靈石，靈石一停，他就不動。付了靈石他替你做事，做完了，他還是門派的：你拿不到圖，改不了心，也帶不回洞府。
>
> 坊裡的人偶就不一樣了，圖紙攤在那裡，誰都能拆。開放碼人偶是一張圖，開放爪是另一張，都放在坊裡，誰都拿得走。
>
> 坊裡被抄走最多次的一張圖，是一具人偶的圖紙，款式叫「拍」。圖紙只有一頁多一點。照這張圖做出來的拍人偶，會的事只有四樣：讀，寫，改，動手。別家的人偶動輒幾十樣本事，拍人偶只有四樣，卻是坊裡取用最多的一款。
>
> 署名只有一個道號：壞邏輯（badlogic）。
>
> 全修仙界有多少具拍人偶，沒有人數過。開放爪就是有門派拿他當底搭出來的，一夜之間，很多修仙者都在談論這一點。也有人取一具回去，放在角落，再沒碰過。
>
> 想養一個懂自己的人偶，只能從能拆開的開始。
>
> 這是其中一具的故事。
