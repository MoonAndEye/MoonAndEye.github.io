我一直希望，這個網站留下來的內容，可以被更多人接觸到。

[![Marv[in]sight：Ideas, code, and insight](/assets/programming/marvinsight-android-app/editorial-split-theme.png)](https://play.google.com/store/apps/details?id=com.marvinswift.marvinsight){:target="_blank" rel="noopener noreferrer"}

這裡有我以前開發 iOS App 時整理的技術筆記，也有後來研究 AI、使用 coding agents，以及開發自己的 Agent 時留下來的紀錄。

有些文章記錄的是最後採用的做法，有些則保留了過程中遇到的問題、做錯的判斷，以及後來為什麼改變方向。

最近開始寫 Agent Build Log 之後，這個目的變得更明確。

我不只想留下 Agent 最後做出了什麼，也想記錄每一次選擇背後的原因。模型怎麼選、工具怎麼接、架構為什麼被推翻，以及一個原本看起來合理的方案，實際做下去之後又遇到了什麼問題。

## 讓內容多一個被找到的機會

這些內容如果只留在網站裡，通常要等到有人剛好搜尋到相關問題，才可能被看見。

所以我做了 Marv[in]sight Android App，讓網站多一個被找到和閱讀的入口。

[![在 Marv[in]sight App 中閱讀網站文章](/assets/programming/marvinsight-android-app/posts-zh.png)](https://play.google.com/store/apps/details?id=com.marvinswift.marvinsight){:target="_blank" rel="noopener noreferrer"}

App 裡可以閱讀網站文章與 Agent Build Log，也可以查看 Marvin Builds 的影片。內容同步到手機後，在沒有網路的情況下仍然可以繼續閱讀。

這個 App 讓多年累積的技術筆記，以及現在持續進行的開發紀錄，可以離開瀏覽器，出現在另一個讀者可能找到它們的地方。

## 我想留下的是開發過程

Agent Build Log 是我現在很重視的一部分。

我會把開發過程中的決定留下來，包括選錯的方案、沒有成功的第一次嘗試，以及隔天又推翻前一天決定的時候。

這些內容不一定都是答案，但它們可以讓其他人看到，一個 Agent 從想法走到實作時，真正會經過哪些事情。

[![在 Marv[in]sight App 中閱讀 Agent Build Log](/assets/programming/marvinsight-android-app/build-log-zh.png)](https://play.google.com/store/apps/details?id=com.marvinswift.marvinsight){:target="_blank" rel="noopener noreferrer"}

我希望這些紀錄不只對現在的我有用。也許之後有人在做類似的事情時，能從其中一次失敗、一個架構選擇，或一段測試結果裡，找到可以參考的東西。

## 網站仍然是內容的起點

Marv[in]sight 第一版現在已經上架 Google Play。

網站仍然會是所有內容的來源。我會繼續把實作過程、失敗和最後的判斷留下來，新的內容也會持續同步進 App。

如果其中一篇文章或一段開發紀錄，剛好幫助某個人少走一點彎路，那這個 App 就完成了我做它的目的。
